# Tut3D (update 2026)

This project is part of the Tutorial on creating a 3D game with LibGDX:

https://monstroussoftware.github.io/2023/11/01/Tutorial-3D-step1.html


To move use WASD keys.  Press SHIFT to go faster.
Use Q and E to turn (or mouse).
Press SPACE to jump.
Press ESC to quit.


## Platforms

- `core`: Main module with the application logic shared by all platforms.
- `lwjgl3`: Primary desktop platform using LWJGL3; was called 'desktop' in older docs.
- `teavm`: Web backend that supports most JVM languages.
